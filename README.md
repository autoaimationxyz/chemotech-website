# Chemotech International — website

Static website for Chemotech International (…a Clean and Conditioning company).
Plain HTML, CSS and JavaScript: no framework or build step needed to host it.
Upload the folder contents to any web host.

## Pages

| File | Page |
|---|---|
| `index.html` | Home |
| `about.html` | About Us: story, vision, mission, values, quality policy, team |
| `products.html` | Our Products: all 6 verticals, 27 categories, 117 products, with search |
| `company-profile.html` | Company Profile: key information, offices, industries, downloads |
| `certifications.html` | Licences & registrations |
| `contact.html` | Contact: both offices + message form |
| `quote.html` | Request Quote form |

## Structure

```
assets/css/style.css   design system (brand colours, one Helvetica/sans-serif stack)
assets/js/main.js      mobile menu, product search, forms
assets/img/            logo, emblem, product photos (from the 2026 company profile)
assets/docs/           downloadable Company Profile and Work Profile PDFs
favicon.png
tools/build.py         generator for all pages (shared header, footer, product data)
```

## Editing

The pages are generated by `tools/build.py`, which holds the shared header and footer,
the full product master list, and each page's copy. To change content, edit that file and run:

```
python3 tools/build.py .
```

Small one-off edits can also be made directly in the HTML files, but they will be
overwritten the next time the generator runs.

## Forms

The Contact and Request Quote forms open the visitor's email app with a pre-filled
message to `info.chemotechinternational@gmail.com` (set in `assets/js/main.js`).
